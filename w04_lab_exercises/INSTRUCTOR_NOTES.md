## Student Workflow

Students will follow this process:
1. Download/clone the project
2. Configure AWS credentials (from AWS Academy)
3. Download PEM file from AWS Academy
4. Set proper permissions on PEM file (see platform-specific guides)
5. Run: `terraform init`
6. Run: `terraform plan`
7. Run: `terraform apply`
8. SSH to instances using their own certificates

## Key Features for Students

### Cross-Platform Support
- **macOS/Linux**: Standard chmod and ssh commands
- **Windows**: PowerShell icacls commands and quoted file paths
- **WSL**: Linux-style commands in Windows Subsystem for Linux
- **PuTTY**: GUI-based SSH client option

### Flexible SSH Configuration
- **Default**: Uses AWS Academy "vockey" key pair (recommended)
- **Advanced**: Students can create custom SSH keys
- **Secure**: No hardcoded keys, students use their own certificates

### Educational Value
- Students learn infrastructure as code principles
- Hands-on experience with AWS services
- SSH key management and security best practices
- Kubernetes cluster deployment and management

## Testing Before Distribution

To test the project works correctly:

1. **Fresh Environment Test**:
   ```bash
   cd /tmp
   cp -r /path/to/project ./test-project
   cd test-project
   terraform init
   terraform plan
   ```

2. **Cross-Platform Test**:
   - Test SSH commands on different platforms
   - Verify permission setting instructions work
   - Check documentation is clear and complete

3. **AWS Academy Compatibility**:
   - Verify "vockey" key pair exists in AWS Academy
   - Test with actual AWS Academy credentials
   - Confirm all services used are available in Academy
